# ผู้ช่วย HelixSR — คู่มือฟีเจอร์

[English](en.md) · [台灣正體中文](zh_TW.md) · [简体中文](zh_CN.md) · [日本語](ja.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Italiano](it.md) · **ไทย** · [Tiếng Việt](vi.md) · [Bahasa Melayu](ms.md) · [हिन्दी](hi.md)

**ผู้ช่วย HelixSR** เป็นเครื่องมือบนเดสก์ท็อป Linux ที่ติดตั้ง เปลี่ยนวิธี อัปเดต และนำ **[HelixSR](https://github.com/lonewolf0622/HelixSR)** ออกจากเกม Steam ของคุณได้ในคลิกเดียว และแสดงขณะเล่นว่า HelixSR ทำงานอยู่จริงหรือไม่

HelixSR นำโครงข่ายอัปสเกล DLSS Model E ของ NVIDIA มารันบนการ์ดจอ AMD (RDNA 1 ขึ้นไป) ในรูปของ compute shader Direct3D 12 ธรรมดา ผ่าน Proton

## เครื่องมือนี้เหมาะกับใคร

HelixSR ไม่มีตัวเลือกการเปิดเกมและไม่มีไฟล์ตั้งค่ากลาง มันทำงานโดยวางไฟล์ DLL ไว้ในโฟลเดอร์ของแต่ละเกม ด้วยหนึ่งในสามวิธีต่อเกม การทำด้วยมือหมายถึง:

1. หาว่าแต่ละเกมมีตัวอัปสเกลอะไรบ้าง (FSR 3.1, DLSS, XeSS, FSR 2) และไฟล์ `.exe` หลักอยู่ที่ไหน
2. เลือกวิธีที่เหมาะกับเกม เปลี่ยนชื่อไฟล์เดิมของเกมเพื่อเก็บไว้ แล้วคัดลอกไฟล์ของ HelixSR ไปไว้ในตำแหน่งที่ถูกต้อง
3. หากใช้วิธี OptiScaler ต้องใส่พาธที่ถูกต้องใน `OptiScaler.ini`
4. ทำทั้งหมดใหม่ทุกครั้งที่ HelixSR อัปเดต และอีกครั้งเมื่อการอัปเดตเกมเขียนทับ HelixSR
5. เปิด `helixsr.log` เพื่อดูว่า HelixSR ทำงานจริงหรือไม่

ผู้ช่วย HelixSR ทำทั้งหมดนี้ได้ในหน้าต่างเดียว setup ของ HelixSR จะถามทีละเกมในเทอร์มินัล ส่วนผู้ช่วย HelixSR แสดงเป็นรายการให้คลิก

## ก่อนเริ่มใช้งาน

> ⚠ **ผู้ช่วย HelixSR ไม่ได้รวม HelixSR มาด้วย และจะไม่ดาวน์โหลดให้คุณ** มันเพียงคัดลอกไฟล์จากโฟลเดอร์ HelixSR ที่คุณเตรียมไว้เอง

1. **ดาวน์โหลด HelixSR** (1.8.0 ขึ้นไป) จาก [GitHub Releases](https://github.com/lonewolf0622/HelixSR/releases) แล้วแตกไฟล์ไว้ในโฟลเดอร์ที่จะเก็บไว้ใช้ เช่น โฟลเดอร์ home
2. **รัน `./helixsr-setup.sh` ในโฟลเดอร์นั้นหนึ่งครั้ง** จะถามก่อนดาวน์โหลด DLL ของ DLSS จาก NVIDIA แล้วใช้สร้างโครงข่ายของ HelixSR (ประมาณหนึ่งนาที) เมื่อเริ่มถามทีละเกม ตอบ `n` หรือปิดหน้าต่างไปได้เลย: ผู้ช่วย HelixSR จะจัดการเกมให้ หากพบโฟลเดอร์แต่ยังไม่ได้ตั้งค่า ผู้ช่วยจะมีปุ่ม “รัน setup ในเทอร์มินัล” ให้
3. **การ์ดจอ AMD รุ่น RDNA 1 ขึ้นไป** (Radeon RX 5000 ขึ้นไป, Steam Deck, Ryzen APU ที่มีกราฟิก RDNA) การรองรับ Radeon Vega ยังเป็นแบบทดลองใน HelixSR 1.9.0
4. **เกม Direct3D 12 ที่รันผ่าน Proton** และมี FSR 3.1, DLSS, XeSS หรือ FSR 2

เมื่อเปิดครั้งแรก ผู้ช่วย HelixSR จะค้นหาโฟลเดอร์ HelixSR ที่ตั้งค่าแล้วในโฟลเดอร์ home, Downloads, Desktop และ Games คุณเลือกโฟลเดอร์อื่นได้ทุกเมื่อด้วย “เลือกโฟลเดอร์ HelixSR…” หรือคลิกป้าย HelixSR ด้านบน

## สามวิธีที่ HelixSR เข้าไปในเกม

นี่คือสามวิธีของ HelixSR เอง (ตัวอักษรคือคำตอบที่ setup ของ HelixSR ใช้) ผู้ช่วย HelixSR จะแสดงเฉพาะวิธีที่ใช้ได้กับเกมนั้น โดยวิธีเริ่มต้นอยู่ลำดับแรก

| วิธี | เกมต้องมี | สิ่งที่เปลี่ยนในโฟลเดอร์เกม | สิ่งที่ต้องเลือกในเกม |
|---|---|---|---|
| **วิธี FSR** (f ค่าเริ่มต้นของเกมที่มี FSR 3.1) | FSR 3.1 | `amd_fidelityfx_upscaler_dx12.dll` (หรือ `amd_fidelityfx_dx12.dll`) ของเกมถูกแทนที่ด้วย HelixSR และเก็บไฟล์ของเกมไว้เป็น `*.original.dll` | **AMD FSR** |
| **วิธี OptiScaler** (o) | DLSS, XeSS หรือ FSR 2 | วาง OptiScaler (เวอร์ชันทางการในโฟลเดอร์ HelixSR ของคุณ) ข้างไฟล์ `.exe` ของเกม โดยให้แบ็กเอนด์ FSR 3.1 ชี้ไปที่โฟลเดอร์ `HelixSR` ข้าง ๆ ทุกไฟล์ที่ถูกแทนที่จะย้ายไปไว้ที่ `HelixSR/backup` | **DLSS** (FSR หรือ XeSS ก็ได้) |
| **วิธี DLSS** (d ทดลอง) | DLSS | วางตัวโหลด DLSS ของ HelixSR เป็น `dxgi.dll` และ HelixSR เป็น `nvngx.dll` ข้างไฟล์ `.exe` ของเกม | **DLSS** |

## ฟีเจอร์

### 1. สแกนเกม Steam และตัวอัปสเกลของแต่ละเกม

- เมื่อเปิดครั้งแรกจะสแกนคลังเกม Steam ทั้งหมด (รวมถึงในไดรฟ์อื่น) หลังติดตั้งเกมใหม่ให้คลิก “⟳ สแกนเกม Steam ใหม่”
- ค้นหา DLL ของ FSR 3.1, DLSS, XeSS และ FSR 2 ในโฟลเดอร์ของแต่ละเกม และหาโฟลเดอร์ของไฟล์ `.exe` หลักจากข้อมูลการเปิดเกมของ Steam (รองรับตัวเปิดเกมและ `*-Shipping.exe` ของ Unreal)
- เกมที่มี**ระบบป้องกันการโกง** (Easy Anti-Cheat, BattlEye) จะมีเครื่องหมายกำกับ
- ชื่อเกมแสดงตามภาษาของหน้าจอ (ชื่อภาษาท้องถิ่นของ Steam) และเรียงตามภาษานั้น เกมที่ใช้ HelixSR ได้จะอยู่ด้านบน และเปิดตัวกรอง “เกมที่ใช้ HelixSR ได้” ไว้เป็นค่าเริ่มต้น

### 2. ติดตั้งในคลิกเดียว

- คลิก “ติดตั้ง HelixSR” เพื่อติดตั้งด้วยวิธีเริ่มต้น หรือคลิกลูกศรข้าง ๆ เพื่อเลือกวิธีอื่น ทุกวิธีจะบอกว่าต้องเลือกอะไรในเกม
- ก่อนเปลี่ยนแปลงใด ๆ เครื่องมือจะตรวจว่าโฟลเดอร์ HelixSR ตั้งค่าแล้ว (สร้างโครงข่ายแล้ว) และเกมไม่ได้กำลังทำงาน
- วิธี DLSS จะอธิบายความเสี่ยงก่อนและขอให้ยืนยัน เกมที่มีระบบป้องกันการโกงก็จะขอให้ยืนยันด้วย
- เมื่อเสร็จ บันทึกจะบอกอย่างละเอียดว่าแทนที่ไฟล์ใด เก็บไฟล์ของเกมไว้ที่ไหน และต้องเลือกอะไรในเกม

### 3. เปลี่ยนวิธี อัปเดต และซ่อมแซม

- **เปลี่ยนวิธี**: “เพิ่มเติม” → “เปลี่ยนเป็น…” จะนำวิธีปัจจุบันออกก่อน (คืนทุกอย่างกลับ) แล้วจึงติดตั้งวิธีใหม่ การตั้งค่า HelixSR ของคุณจะย้ายตามไปด้วย
- **อัปเดต**: เมื่อโฟลเดอร์ HelixSR ของคุณมีเวอร์ชันใหม่กว่าในเกม (HelixSR เวอร์ชันใหม่ หรือสร้างโครงข่ายใหม่) เกมจะแสดง “↑ มี HelixSR …” และปุ่ม “↑ อัปเดต” ส่วน “↑ อัปเดตทั้งหมด” จะอัปเดตทุกเกมพร้อมกัน
- **ซ่อมแซม**: การอัปเดตเกมหรือ “ตรวจสอบความสมบูรณ์ของไฟล์เกม” ใน Steam อาจนำไฟล์ของเกมกลับมาทับ HelixSR เกมจะแสดงว่าเกิดอะไรขึ้นพร้อมปุ่ม “ซ่อมแซม” ซึ่งจะนำ HelixSR กลับเข้าที่ และเก็บไฟล์ใหม่ของเกมไว้เป็นสำรอง
- เมื่อมีโฟลเดอร์ HelixSR ที่ใหม่กว่าและตั้งค่าแล้วปรากฏใน Downloads (หรือที่อื่นที่ใช้กันบ่อย) เครื่องมือจะถามหนึ่งครั้งว่าจะเปลี่ยนไปใช้หรือไม่

### 4. นำออก

- “นำออก” จะเอา HelixSR ออก และคืนทุกไฟล์ที่มันแทนที่หรือย้ายไปให้กลับเป็นเหมือนเดิมทุกประการ
- การตั้งค่า HelixSR ของเกม (`helixsr.ini`) จะถูกเก็บไว้ เว้นแต่คุณติ๊ก “นำการตั้งค่า HelixSR ของเกมนี้ออกด้วย”
- ไฟล์ที่คุณวางไว้เองในโฟลเดอร์ `my-fsr` ของเกมจะไม่ถูกลบเด็ดขาด

### 5. ตั้งค่า HelixSR โดยไม่ต้องแก้ไฟล์

“⚙ ตั้งค่า” จะแก้ไข `helixsr.ini` ของเกมผ่านแบบฟอร์ม มีให้เฉพาะการตั้งค่าที่ README ของ HelixSR ระบุไว้:

| กลุ่ม | การตั้งค่า | ค่า |
|---|---|---|
| ความคมชัด | ตัวเพิ่มความคม | ค่าเริ่มต้น, ปิด, NVIDIA, RCAS |
| | ระดับความคม | 0.00 – 1.00 |
| | ใช้ตามแถบปรับความคมของเกม | ค่าเริ่มต้น, ใช่, ไม่ |
| การอัปสเกล (HelixSR 1.9.0 ขึ้นไป) | โครงข่าย int8 | ค่าเริ่มต้น (อัตโนมัติ), อัตโนมัติ, เปิด, ปิด |
| | ขั้นสุดท้ายในโหมด Ultra Performance | ค่าเริ่มต้น (Lanczos), Lanczos, EASU (FSR 1) |
| ความเข้ากันได้ | ขนาด wave | ค่าเริ่มต้น, 64, 32 |

“ค่าเริ่มต้น” จะไม่เขียนบรรทัดนั้น HelixSR จึงใช้ค่าเริ่มต้นของตัวเอง คอมเมนต์และบรรทัดอื่น ๆ ในไฟล์จะคงไว้ตามเดิม ไฟล์จะถูกเขียนข้าง DLL ของ HelixSR ตามวิธีของเกม (โฟลเดอร์ `HelixSR` ของเกม ข้าง DLL ของ FSR ของเกม หรือข้างไฟล์ `.exe`)

### 6. สถานะ HelixSR แบบสด (สิ่งที่ทำงานอยู่จริง)

ตรวจเกม Steam ที่กำลังทำงานทุก 3 วินาที:

- Proton โหลด DLL ของ Windows จากไฟล์โดยตรง เครื่องมือจึงดูใน `/proc/<pid>/maps` ได้ว่าเกม**โหลด HelixSR จริงหรือไม่** (รวมถึง OptiScaler หรือตัวโหลด DLSS)
- HelixSR จะถูกโหลดเมื่อเกมเริ่มใช้ตัวอัปสเกลเท่านั้น ดังนั้น “ยังไม่ได้โหลด HelixSR” จะบอกว่าคุณต้องเลือกอะไรในการตั้งค่ากราฟิกของเกม
- อ่าน `helixsr.log` ของการเล่นครั้งนี้: แสดงขนาด wave ของเคอร์เนลโครงข่ายและบรรทัดข้อผิดพลาด “เพิ่มเติม” → “ดู helixsr.log” จะแสดงบันทึกทั้งหมดพร้อมปุ่มคัดลอก
- บนการ์ดจอ **RDNA 3 ขึ้นไป** ในเกมที่ใช้วิธี OptiScaler หากบันทึกแสดง wave32 README ของ HelixSR แนะนำให้ตั้ง `WaveSize = 64` เครื่องมือจะตรวจพบและมีปุ่ม “ตั้ง WaveSize = 64” ให้คลิกเดียว
- ป้ายการ์ดจอด้านบนแสดงรุ่นของการ์ดจอคุณ (เช่น “AMD RDNA 3 (gfx1100)”)

### 7. ข้อความซ้อนเมื่อเปิดเกม

หากผู้ช่วย HelixSR เปิดอยู่ตอนที่เกมที่มี HelixSR เริ่มทำงาน ทันทีที่ HelixSR ถูกโหลด จะมีการ์ดเล็ก ๆ ปรากฏที่มุมขวาล่างประมาณ 10 วินาที แสดงเวอร์ชัน วิธี และขนาด wave (ครั้งเดียวต่อการเปิดเกม เกมที่ทำงานอยู่ก่อนเปิดเครื่องมือจะไม่แสดง) หากผ่านไป 90 วินาทียังไม่โหลด HelixSR การ์ดจะบอกว่าต้องเลือกอะไรในเกม ข้อความซ้อนเป็นหน้าต่าง X11 (XWayland) แยกต่างหาก ไม่แย่งโฟกัส และให้คลิกเมาส์ผ่านได้ ปิดได้ด้วยช่องทำเครื่องหมายบนแถบเครื่องมือ จะไม่แสดงในโหมดเกมของ Steam Deck (gamescope)

### 8. เปิดเกม ค้นหา และกรอง

- ทุกแถวมีปุ่ม “▶ เปิดเกม” (ผ่าน `steam://rungameid/<AppID>`) ขณะเกมทำงานจะแสดง “กำลังทำงาน”
- ค้นหาด้วยชื่อเกม (ภาษาใดก็ได้) หรือ App ID ตัวกรอง: เกมที่ใช้ HelixSR ได้, ติดตั้งแล้ว, ยังไม่ได้ติดตั้ง, ต้องอัปเดตหรือซ่อมแซม, กำลังทำงาน, เกมทั้งหมด

### 9. ภาษาหน้าจอ 12 ภาษา

台灣正體中文, 简体中文, English, 日本語, Deutsch, Français, Español, Italiano, ไทย, Tiếng Việt, Bahasa Melayu, हिन्दी เปิดครั้งแรกจะใช้ภาษาของระบบ เปลี่ยนได้ที่มุมขวาบน (มีผลทันทีและจดจำไว้)

### 10. ออกแบบโดยคำนึงถึงความปลอดภัย

- จะไม่เปลี่ยนแปลงสิ่งใดหากโฟลเดอร์ HelixSR ยังไม่ได้ตั้งค่า หรือเกมกำลังทำงานอยู่
- ทุกไฟล์ที่ HelixSR แทนที่จะถูกเก็บไว้ (`*.original.dll` หรือ `HelixSR/backup`) และทุกไฟล์ที่คัดลอกจะถูกตรวจสอบทีละไบต์
- `OptiScaler.ini` ที่คุณมีอยู่เดิมจะถูกสำรองและคืนเมื่อนำออก ส่วน DLL ของ FSR ที่คุณแทนที่เองในโฟลเดอร์ `HelixSR` ของเกมจะถูกเก็บไว้เมื่ออัปเดต
- วิธี DLSS และเกมที่มีระบบป้องกันการโกงต้องได้รับการยืนยันอย่างชัดเจน

## ทำงานร่วมกับ setup ของ HelixSR เอง

ผู้ช่วย HelixSR เขียนบันทึกการติดตั้ง (`helixsr-install.json`) ไฟล์สำรอง และชื่อไฟล์แบบเดียวกับ setup ของ HelixSR ดังนั้น:

- เกมที่ตั้งค่าด้วย `helixsr-setup.sh` จะแสดงเป็นติดตั้งแล้วในผู้ช่วย HelixSR พร้อมวิธี และเปลี่ยน อัปเดต หรือนำออกจากที่นี่ได้
- เกมที่ตั้งค่าด้วยผู้ช่วย HelixSR จะเป็นที่รู้จักของ setup ของ HelixSR และ `helixsr-uninstall.sh` ซึ่งอัปเดตหรือนำออกได้

## การติดตั้งผู้ช่วย HelixSR

**AppImage (แนะนำ)**: มี Python และ Qt มาในตัว ไม่ต้องติดตั้งอะไรเพิ่ม

1. ดาวน์โหลด `HelixSR_Assistant-<เวอร์ชัน>-x86_64.AppImage` จากหน้า [Releases](https://github.com/mosesmoon/helixsr-assistant/releases)
2. ทำให้รันได้: คลิกขวาที่ไฟล์ → Properties → Permissions แล้วเปิด “Allow executing file as program” (ข้อความต่างกันไปตามโปรแกรมจัดการไฟล์)
3. ดับเบิลคลิกเพื่อเปิดผู้ช่วย HelixSR

หรือในเทอร์มินัล:

```bash
chmod +x HelixSR_Assistant-*-x86_64.AppImage
./HelixSR_Assistant-*-x86_64.AppImage
```

หากเปิดไม่ได้ ระบบอาจไม่มี FUSE ให้รันด้วย `./HelixSR_Assistant-*-x86_64.AppImage --appimage-extract-and-run` แทน

**จากซอร์สโค้ด**: ต้องใช้ Python 3.11 ขึ้นไปและ PyQt6 (Arch: `sudo pacman -S python-pyqt6`)

```bash
./helixsr-assistant    # รันโดยตรง
./install.sh           # ติดตั้งไปที่ ~/.local/share/helixsr-assistant และเพิ่มรายการในเมนูแอป
```

## ข้อจำกัดที่ทราบ

- **รองรับเฉพาะเกม Steam** สำหรับเกมจากร้านค้าอื่น ให้ใช้ setup ของ HelixSR เอง (ลากโฟลเดอร์เกมเข้าไป)
- HelixSR ใช้ได้เฉพาะเกม Direct3D 12 เกมที่มี DLL ของ DLSS หรือ FSR อาจยังเป็น Vulkan หรือ Direct3D 11 ซึ่ง HelixSR จะไม่มีผลใด ๆ
- HelixSR เปลี่ยนแปลงเร็วมาก ผู้ช่วย HelixSR ต้องใช้ HelixSR 1.8.0 ขึ้นไป และทำตามโครงสร้างของ 1.8.x และ 1.9.x หาก HelixSR เวอร์ชันถัดไปเปลี่ยนวิธีติดตั้งเกม ให้ใช้ setup ของ HelixSR เองจนกว่าผู้ช่วย HelixSR จะอัปเดต
- ข้อความซ้อนจะไม่แสดงในโหมดเกมของ Steam Deck (gamescope) และเกมที่เต็มจอแบบ exclusive บน Wayland โดยตรงอาจบังมัน
- ในภาษาไทย เวียดนาม มาเลย์ และฮินดี เมนูคลิกขวาจะเป็นภาษาอังกฤษ (Qt ไม่มีคำแปลทางการของภาษาเหล่านี้) Steam ไม่มีชื่อเกมภาษามาเลย์และฮินดี สองภาษานี้จึงแสดงชื่อต้นฉบับเสมอ

## ตำแหน่งที่เก็บข้อมูล

| ตำแหน่ง | เนื้อหา |
|---|---|
| `~/.config/helixsr-assistant/state.json` | สถานะของผู้ช่วย HelixSR เอง: โฟลเดอร์ HelixSR แคชรายการเกม ภาษาหน้าจอ การตั้งค่าข้อความซ้อน |
| `<เกม>/…/HelixSR/helixsr-install.json` ข้าง DLL ของ FSR ของเกม | บันทึกการติดตั้งของ HelixSR (ใช้ร่วมกับ setup ของ HelixSR) |
| `<เกม>/…/helixsr.ini` | การตั้งค่า HelixSR ของเกมนั้น |
| `<เกม>/…/helixsr.log` | สิ่งที่ HelixSR รายงานเมื่อเปิดเกมครั้งล่าสุด |

## สัญญาอนุญาต

ผู้ช่วย HelixSR เป็นเครื่องมืออิสระที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้องหรือได้รับการรับรองจากผู้สร้าง HelixSR, NVIDIA, AMD หรือโครงการ OptiScaler และไม่มีไฟล์ใด ๆ ของพวกเขา HelixSR ใช้ได้ฟรีภายใต้ HelixSR Freeware License หลังจากรัน setup ของ HelixSR แล้ว DLL ของ HelixSR จะมีโครงข่ายของ NVIDIA อยู่ ผู้ช่วย HelixSR เพียงคัดลอกระหว่างโฟลเดอร์ในเครื่องของคุณเท่านั้น ห้ามแชร์หรืออัปโหลดไฟล์เหล่านี้เด็ดขาด
