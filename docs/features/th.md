# ผู้ช่วย Scaler — คู่มือฟีเจอร์

[English](en.md) · [台灣正體中文](zh_TW.md) · [简体中文](zh_CN.md) · [日本語](ja.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Italiano](it.md) · **ไทย** · [Tiếng Việt](vi.md) · [Bahasa Melayu](ms.md) · [हिन्दी](hi.md)

**ผู้ช่วย Scaler** เป็นเครื่องมือเดสก์ท็อปบน Linux ที่ให้คุณเลือกตัวอัปสเกลของเกม Steam แต่ละเกม — **DLSS 3.7 ([HelixSR](https://github.com/lonewolf0622/HelixSR))**, **FSR 4.1** (Exact หรือ Lossy จาก [fsr4-shader-performance-overrides](https://github.com/zgauthier2000/fsr4-shader-performance-overrides) หรือของ AMD เองบน RX 9000) หรือ **FSR 3** — แล้วติดตั้ง เปลี่ยน อัปเดต ซ่อมแซม และลบออกได้ในคลิกเดียว และยังแสดงว่าตัวอัปสเกลทำงานจริงหรือไม่ขณะเล่น

## เหมาะกับใคร

การใส่ตัวอัปสเกลที่ดีกว่าให้เกมบน Linux ด้วยมือต้อง:

1. หาว่าเกมมีตัวอัปสเกลอะไร (DLSS, XeSS, FSR 2, FSR 3.1) ใช้กราฟิก API อะไร และไฟล์ `.exe` หลักอยู่ที่ไหน
2. วาง OptiScaler ข้างไฟล์ `.exe` ด้วยชื่อไฟล์ที่เกมยอมรับ พร้อม DLL FidelityFX ที่ต้องใช้ และแก้ `OptiScaler.ini` ให้ตรงกับตัวอัปสเกลที่ต้องการ
3. เพิ่ม `WINEDLLOVERRIDES` ในตัวเลือกการเปิดเกมของ Steam เมื่อชื่อไฟล์นั้นต้องใช้ — โดยไม่ทำให้ของเดิมเสีย
4. ดาวน์โหลด DLL FSR 4.1 ที่ตรงกับ GPU หรือตั้งค่า HelixSR ตาม README ของมัน
5. ทำซ้ำทุกครั้งที่อัปเดต และอีกครั้งเมื่อการอัปเดตเกมเขียนทับไฟล์

ผู้ช่วย Scaler ทำทั้งหมดนี้ในหน้าต่างเดียว และเก็บทุกไฟล์ที่แทนที่ไว้ เมื่อลบออก เกมจะกลับเป็นเหมือนเดิมทุกประการ

## ตัวเลือกของแต่ละเกม

ตัวเลือกที่มีให้ขึ้นอยู่กับกราฟิก API และตัวอัปสเกลของเกม เกมต้องมีตัวอัปสเกลอย่างน้อยหนึ่งตัวอยู่แล้ว (DLSS, XeSS, FSR 2 หรือ FSR 3.1) ซึ่ง OptiScaler และ HelixSR จะเข้าไปรับช่วงต่อ

| ตัวเลือก | เกมต้องมี | สิ่งที่ใส่ในโฟลเดอร์เกม | เลือกในเกม |
|---|---|---|---|
| **DLSS 3.7 (HelixSR) · วิธี FSR** | Direct3D 12, FSR 3.1 | แทนที่ DLL FSR 3.1 ของเกมด้วย HelixSR (ไฟล์เดิมเก็บเป็น `*.original.dll`) | AMD FSR |
| **DLSS 3.7 (HelixSR) · วิธี OptiScaler** | Direct3D 12, DLSS, XeSS หรือ FSR 2 | OptiScaler ข้าง `.exe` ชี้ไปที่โฟลเดอร์ `HelixSR` | DLSS |
| **DLSS 3.7 (HelixSR) · วิธี DLSS** (ทดลอง) | Direct3D 12, DLSS | ตัวโหลด DLSS ของ HelixSR (`dxgi.dll`) และ HelixSR ในชื่อ `nvngx.dll` | DLSS |
| **FSR 4.1 Exact** | ตัวอัปสเกลใดก็ได้จากสี่ตัว | OptiScaler ข้าง `.exe`; DLL FidelityFX และ DLL FSR 4.1 แบบ Exact ในโฟลเดอร์ `ScalerAssistant` | DLSS, FSR หรือ XeSS |
| **FSR 4.1 Lossy** | เหมือนกัน | เหมือนกัน แต่ใช้ DLL FSR 4.1 แบบ Lossy | DLSS, FSR หรือ XeSS |
| **FSR 4.1.2 Lite / Lite Lossy** | เหมือนกัน | เหมือนกัน แต่ใช้ DLL FSR 4.1 แบบ 4.1.2l-exact / 4.1.2l-lossy | DLSS, FSR หรือ XeSS |
| **FSR 4.1 (AMD)** — ใช้แทน Exact / Lossy บน RX 9000 (RDNA 4) | เหมือนกัน | เหมือนกัน แต่ใช้ DLL FSR 4.1 ของ AMD เอง | DLSS, FSR หรือ XeSS |
| **FSR 3** | เหมือนกัน | เหมือนกัน OptiScaler ใช้ FSR 3.1.5 | DLSS, FSR หรือ XeSS |

- **Exact** ให้ภาพเหมือน FSR 4.1 ของ AMD ทุกไบต์ แต่เชดเดอร์เร็วกว่า **Lossy** เร็วยิ่งขึ้นแต่ภาพเปลี่ยนเล็กน้อย ผู้ช่วย Scaler จะแสดง `WARNING.txt` ของมันหนึ่งครั้งก่อนใช้ครั้งแรก ถ้าไม่แน่ใจให้เลือก Exact
- **Lossy** ตั้งแต่ DLL ของ dll-2026-10-29 คือ Lossy2 เดิมที่ฝึกเพิ่ม (Lossy แบบเก่าถูกนำออก): จุดดำในใบไม้ลดลงมาก แต่ตามการเปลี่ยนเป็นสว่างได้ช้าลง **Lite** และ **Lite Lossy** ใช้เครือข่าย FSR 4.1.2 Lite ขนาดเล็กของ AMD (น่าจะเป็นตัวที่ไดรเวอร์ AMD ใช้กับกราฟิกในตัว): Lite ให้ภาพตรงกับ Lite ของ AMD ทุกไบต์และเร็วกว่าเล็กน้อย Lite Lossy รันเครือข่ายทุก ๆ สองเฟรมและเป็นบิลด์ที่เร็วที่สุด ภาพใกล้เคียง Lite Lite แม่นยำน้อยกว่า FSR 4 เต็มรูปแบบเล็กน้อยในภาพนิ่งและการเคลื่อนไหวบางแบบ แต่ดีกว่าในบางแบบ Lossy และ Lite Lossy จะแสดง `WARNING.txt` ของตัวเองหนึ่งครั้ง เกมที่ตั้งค่าด้วย Lossy2 จะแสดงว่าอัปเดตได้และจะเปลี่ยนเป็น Lossy
- HelixSR ใช้ได้เฉพาะเกม **Direct3D 12** จึงมี DLSS 3.7 ให้เลือกเฉพาะเกมเหล่านั้น FSR 4.1 และ FSR 3 ใช้กับเกม **Direct3D 11 และ Vulkan** ได้ด้วย: FSR 3 ทำงานแบบเนทีฟ ส่วน FSR 4.1 ผ่านเส้นทาง Direct3D 12 ของ OptiScaler (ทดสอบน้อยกว่าเกม Direct3D 12)
- คลิก **"เลือกตัวอัปสเกล"** ในแถวของเกม (หรือ **"ตัวอัปสเกล"** เมื่อติดตั้งแล้ว): DLSS 3.7 (HelixSR) จะเปิดเมนูย่อยแสดงวิธีต่าง ๆ ตัวเลือกปัจจุบันมีเครื่องหมายถูก การเปลี่ยนจะลบตัวปัจจุบันก่อนและคืนทุกอย่างกลับ

## ก่อนเริ่ม

- **FSR 4.1 และ FSR 3** ไม่ต้องใช้อะไรเพิ่ม: ครั้งแรกที่เลือก ผู้ช่วย Scaler จะถามว่าจะดาวน์โหลด OptiScaler และ DLL FSR 4.1 ที่เหมาะกับ GPU หรือไม่ (ดู "ไฟล์ดาวน์โหลด")
- **DLSS 3.7** ต้องใช้ HelixSR ซึ่งผู้ช่วย Scaler ไม่ได้รวมไว้ ดาวน์โหลด HelixSR 1.8.0 ขึ้นไปจาก [GitHub Releases](https://github.com/lonewolf0622/HelixSR/releases) แตกไฟล์ไว้ในโฟลเดอร์ที่จะเก็บไว้ แล้วรัน `./helixsr-setup.sh` ที่นั่นหนึ่งครั้ง (มันจะสร้างโครงข่ายของ HelixSR บนพีซีของคุณ เมื่อถามเรื่องเกมตอบ `n` ได้) ปุ่ม **HelixSR** ด้านบนอธิบายเรื่องนี้ไว้ และผู้ช่วย Scaler จะหาโฟลเดอร์ HelixSR ที่ตั้งค่าแล้วในโฟลเดอร์ home, Downloads, Desktop หรือ Games เอง
  วิธีที่ง่ายกว่า: กด **ดาวน์โหลดและสร้าง HelixSR** ในหน้าต่างนั้น (HelixSR 2.0 ขึ้นไป) Scaler Assistant จะทำขั้นตอนทั้งหมดนี้ให้โดยไม่ต้องใช้เทอร์มินัล
- เกมทำงานผ่าน **Proton** HelixSR ทำมาสำหรับ GPU AMD (RDNA 1 ขึ้นไป) FSR 4.1 Exact / Lossy ทำมาสำหรับ Radeon RX 7000 / RX 6000 และกราฟิก Radeon ในตัว (รวม Steam Deck) GPU อื่นน่าจะใช้ได้แต่ผู้สร้างยังไม่ได้ทดสอบ FSR 4.1 ใช้ไม่ได้กับการ์ดจอ Radeon RX 5000 (RDNA 1) (ทุกเวอร์ชันแสดงแค่ภาพสีดำ) ผู้ช่วย Scaler จึงแสดงตัวเลือกนี้เป็นสีเทาบนการ์ดเหล่านี้ ยังใช้ FSR 3 และ DLSS 3.7 (HelixSR) ได้

## ฟีเจอร์

### 1. สแกนเกม Steam

- ครั้งแรกที่เปิดจะสแกนคลัง Steam ทั้งหมด (รวมไดรฟ์อื่น) หลังติดตั้งเกมใหม่ให้คลิก "⟳ สแกนเกม Steam ใหม่"
- สำหรับแต่ละเกม: DLL อัปสเกลที่มี โฟลเดอร์ของ `.exe` หลัก (จากข้อมูลการเปิดเกมของ Steam รองรับตัวเปิดเกมและ `*-Shipping.exe` ของ Unreal) **กราฟิก API** (อ่านจากตาราง import ของ `.exe`: DX12, DX11 หรือ Vulkan) และมี **ระบบป้องกันการโกง** หรือไม่ (Easy Anti-Cheat, BattlEye)
- ชื่อเกมตามภาษาของหน้าจอ (ชื่อท้องถิ่นของ Steam) เกมที่อัปสเกลได้อยู่ด้านบน

### 2. ชื่อไฟล์ของ OptiScaler ที่ใช้ได้ในเกม

เกมจะโหลด OptiScaler เป็น DLL ระบบที่วางข้าง `.exe` ชื่อจะถูกเลือกตามลำดับ:

1. ชื่อที่คุณเลือกให้เกมนั้น ("เพิ่มเติม" → "ชื่อไฟล์ของ OptiScaler…")
2. ชื่อของ OptiScaler ที่มีอยู่แล้ว
3. ชื่อที่ [รายการความเข้ากันได้ของ OptiScaler](https://github.com/optiscaler/OptiScaler/wiki) ระบุไว้สำหรับเกมนั้น (เช่น `d3d12.dll` หรือ `winmm.dll`)
4. `winmm.dll` สำหรับเกม Vulkan
5. ชื่ออื่นที่ว่าง (`winmm.dll`, `version.dll` …) เมื่อเกมหรือม็อดอื่น (เช่น ReShade) มี `dxgi.dll` อยู่แล้ว หรือเมื่อตัวเลือกการเปิดเกมของคุณกำหนดชื่อนั้นเป็นเวอร์ชันในตัว
6. นอกนั้นใช้ `dxgi.dll`

ไฟล์ที่มีอยู่แล้วจะไม่ถูกเขียนทับ: จะย้ายไปที่ `ScalerAssistant/backup` (`HelixSR/backup` สำหรับ DLSS 3.7) และคืนกลับเมื่อลบออก

### 3. ตัวเลือกการเปิดเกมของ Steam: เพิ่มเฉพาะที่จำเป็น ของคุณคงเดิม

ภายใต้ Proton, `dxgi.dll` และ `d3d12.dll` โหลดได้เลย ชื่ออื่นต้องมี `WINEDLLOVERRIDES="<ชื่อ>=n,b"` ในตัวเลือกการเปิดเกม ซึ่งผู้ช่วย Scaler จะเพิ่มให้:

- **แทรกเฉพาะรายการนั้นรายการเดียว** ถ้ามี `WINEDLLOVERRIDES` อยู่แล้วจะต่อท้าย `;winmm=n,b` ในค่านั้น ถ้าไม่มีจะใส่ `WINEDLLOVERRIDES="winmm=n,b"` ไว้ด้านหน้า (เติม `%command%` ถ้ายังไม่มี) ส่วนอื่นไม่เปลี่ยน ตัวอย่าง: `-dx12 %command%` กลายเป็น `WINEDLLOVERRIDES="winmm=n,b" -dx12 %command%`
- **นำออกเฉพาะรายการนั้น** เมื่อลบหรือเปลี่ยนชื่อ OptiScaler ถ้าระหว่างนั้นคุณไม่ได้แก้ตัวเลือก จะกลับเป็นแบบเดิมทุกตัวอักษร ถ้าแก้ไปแล้ว จะลบเฉพาะข้อความที่แทรกและเก็บการแก้ไขของคุณไว้
- รายการที่คุณมีอยู่แล้วสำหรับชื่อนั้นจะไม่ถูกแตะต้องและไม่ถูกลบภายหลัง ถ้าตัวเลือกของคุณตั้งชื่อนั้นเป็นเวอร์ชันในตัวของ Wine ผู้ช่วย Scaler จะใช้ชื่ออื่นแทนการแก้การตั้งค่าของคุณ
- ถ้ารายการหายไปภายหลัง เกมจะแสดง "ไม่มีตัวเลือกการเปิดเกม" และ "ซ่อมแซม" จะเพิ่มกลับ
- ขณะ Steam เปิดอยู่ จะเปลี่ยนตัวเลือกผ่าน Steam เองเมื่อพอร์ตดีบักของมันใช้ได้ (แบบที่ Decky Loader ใช้) มิฉะนั้นผู้ช่วย Scaler จะเสนอให้ปิด Steam เขียนการเปลี่ยนแปลง แล้วเปิด Steam ใหม่ — ก่อนแตะไฟล์ใด ๆ ของเกม

### 4. ไฟล์ดาวน์โหลด (FSR 4.1 และ FSR 3)

คลิกปุ่ม **OptiScaler** ด้านบน (หรือปุ่ม GPU):

- **OptiScaler 0.9.4** (พร้อม DLL FidelityFX ของ AMD: FSR 3 และ FSR 4.1 ของ AMD รวมถึง fakenvapi) และ **FSR 4.1 Exact / Lossy / Lite / Lite Lossy** ในบิลด์สำหรับ GPU ของคุณ: การ์ด RX 7000, การ์ด RX 6000, กราฟิก RDNA 3 ในตัวซีพียู (รวมถึง GeForce, Intel Arc และ GPU อื่น) หรือ Steam Deck และกราฟิก RDNA 2 ในตัวซีพียู ทุกบิลด์ใช้ได้กับทั้งหมด และบิลด์สำหรับ GPU ของคุณเร็วที่สุด หากเกมแครชเมื่อใช้ Exact ให้เลือกบิลด์สำหรับกราฟิกในตัว
- จะไม่ดาวน์โหลดอะไรจนกว่าคุณจะยอมรับ ไฟล์ทุกไฟล์เป็นรุ่นที่กำหนดไว้ ตรวจขนาดและ SHA-256 ก่อนแตกไฟล์ เก็บเฉพาะไฟล์ที่เกมต้องใช้ไว้ใน `~/.local/share/scaler-assistant/components/`
- **บิลด์ FSR 4.1**: เลือกอัตโนมัติตาม GPU (RX 9000 / RDNA 4 → FSR 4.1 ของ AMD เอง, กราฟิกในตัวและ Steam Deck → บิลด์สำหรับกราฟิกในตัว, GPU อื่น → บิลด์สำหรับการ์ดจอแยก) หรือเลือกเอง บน RDNA 4 จะไม่ใช้ DLL ที่ดัดแปลงเลย บน GPU อื่นจะตั้ง OptiScaler ให้ใช้โมเดล INT8 ของ FSR 4
- "ลบไฟล์ดาวน์โหลด" จะลบไฟล์เหล่านี้ สำเนาในเกมยังอยู่

### 5. สิ่งที่เปลี่ยนใน OptiScaler.ini

เปลี่ยนเฉพาะบรรทัดที่จำเป็นในส่วนของมันเอง บรรทัดอื่นและคอมเมนต์คงเดิม:

| คีย์ | FSR 4.1 | FSR 3 |
|---|---|---|
| `Dx12Upscaler` | `fsr31` | `fsr31` |
| `Dx11Upscaler`, `VulkanUpscaler` | `fsr31_12` (ผ่าน Direct3D 12) | `fsr31` (เนทีฟ) |
| `UpscalerIndex` | `0` (FSR 4) | `1` (FSR 3.1.5) |
| `Fsr4Update` | `true` | `false` |
| `Fsr4ForceEnableInt8` | `true` ก่อน RDNA 4 | `auto` |
| `FfxDx12Path`, `FfxDx12SRPath`, `FfxDx12FGPath`, `FfxVkPath` | DLL ในโฟลเดอร์ `ScalerAssistant` ของเกม | เหมือนกัน |

`OptiScaler.ini` ที่มีอยู่แล้วจะถูกสำรองก่อน และคืนกลับเมื่อลบออก

### 6. เปลี่ยน อัปเดต ซ่อมแซม ลบออก

- **เปลี่ยน** จากเมนูตัวอัปสเกล: ลบตัวเลือกปัจจุบันก่อนแล้วติดตั้งตัวใหม่ ระหว่าง FSR 4.1 Exact, Lossy และ FSR 3 จะเปลี่ยนเฉพาะ DLL FSR และ `OptiScaler.ini`
- **อัปเดต**: เกมจะแสดง "↑ มี HelixSR … ให้ใช้" เมื่อโฟลเดอร์ HelixSR มีบิลด์ใหม่กว่า หรือ "↑ มีไฟล์ดาวน์โหลดที่ใหม่กว่า" เมื่อมี OptiScaler / FSR 4.1 ที่ใหม่กว่า (หรือบิลด์ FSR 4.1 อื่น) "↑ อัปเดตทั้งหมด" จะอัปเดตทุกเกม
- **ซ่อมแซม**: การอัปเดตเกมหรือ "ตรวจสอบความสมบูรณ์ของไฟล์เกม" อาจทำให้ไฟล์เดิมของเกมกลับมา เกมจะแสดงสิ่งที่เกิดขึ้น และ "ซ่อมแซม" จะนำตัวอัปสเกลกลับ โดยเก็บไฟล์ใหม่ของเกมเป็นสำรอง
- **ลบออก** คืนทุกไฟล์ที่ถูกแทนที่หรือย้าย และนำรายการในตัวเลือกการเปิดเกมออก

### 7. ตั้งค่า HelixSR โดยไม่ต้องแก้ไฟล์

สำหรับ DLSS 3.7 "⚙ ตั้งค่า" จะแก้ `helixsr.ini` ของเกมผ่านฟอร์ม (ความคมชัด โครงข่าย int8 ขั้นสุดท้ายในโหมด Ultra Performance ขนาด wave) "ค่าเริ่มต้น" จะไม่เขียนบรรทัดนั้น บรรทัดอื่นและคอมเมนต์คงเดิม

### 8. สถานะสดและข้อความซ้อน

- ตรวจเกม Steam ที่กำลังทำงานทุก 3 วินาที: `/proc/<pid>/maps` แสดงว่าเกม **โหลดจริง** HelixSR หรือ DLL FSR (และ OptiScaler หรือตัวโหลด DLSS) แล้วหรือไม่ จะยังไม่โหลดจนกว่าเกมจะใช้ตัวอัปสเกล ดังนั้น "ยังไม่ได้โหลด" จะบอกว่าต้องเลือกอะไรในเกม
- สำหรับ HelixSR จะแสดงขนาด wave และข้อผิดพลาดจาก `helixsr.log` ของรอบนี้ บน RDNA 3 ขึ้นไปที่ใช้วิธี OptiScaler จะเสนอ "ตั้งค่า WaveSize = 64" เมื่อบันทึกแสดง wave32
- แผงรายละเอียดของเกม (ปุ่ม ⌄ บนการ์ดของเกม) มี "ดู …log" สำหรับ `helixsr.log` หรือ `OptiScaler.log` โฟลเดอร์ของเกม ชื่อไฟล์ของ OptiScaler และ "⚙ ตั้งค่า" สำหรับ DLSS 3.7
- เมื่อเปิดเกม จะมีการ์ดเล็ก ๆ ที่มุมขวาล่างแสดงผลประมาณ 10 วินาที (หรือคำแนะนำหลัง 90 วินาที) เป็นหน้าต่าง X11 แยกที่ไม่แย่งโฟกัส ปิดได้ด้วยสวิตช์บนแถบเครื่องมือ

### 9. เปิดเกม ค้นหา กรอง ภาษา

- "▶ เปิดเกม" เปิดเกมผ่าน Steam ค้นหาด้วยชื่อ (ภาษาใดก็ได้) หรือ App ID ตัวกรอง: เกมที่อัปสเกลได้ ติดตั้งตัวอัปสเกลแล้ว ยังไม่มีตัวอัปสเกล ต้องอัปเดตหรือซ่อมแซม กำลังทำงาน ทุกเกม
- ภาษาหน้าจอ 12 ภาษา: 台灣正體中文, 简体中文, English, 日本語, Deutsch, Français, Español, Italiano, ไทย, Tiếng Việt, Bahasa Melayu, हिन्दी

### 10. ออกแบบมาให้ปลอดภัย

- ไม่เปลี่ยนอะไรขณะเกมทำงาน ตรวจไฟล์ดาวน์โหลดและโฟลเดอร์ HelixSR ก่อนแตะไฟล์ใด ๆ
- เก็บทุกไฟล์ที่ถูกแทนที่ ตรวจทุกสำเนาทีละไบต์ และตัวเลือกการเปิดเกมเปลี่ยนเฉพาะรายการเดียวตามที่อธิบายไว้
- วิธี DLSS, FSR 4.1 Lossy และเกมที่มีระบบป้องกันการโกงจะถามก่อน อย่าใช้ตัวอัปสเกลที่ดัดแปลงในเกมออนไลน์: ระบบป้องกันการโกงอาจถือว่าเป็นการดัดแปลง

### 11. หน้าตา

- ตามสไตล์ "Liquid Glass" ของ MAKO Assistant: การ์ดหนึ่งใบต่อหนึ่งเกม มีภาพปกจาก Steam ป้ายสถานะ สิ่งที่เกมรองรับ และเมื่อเกมทำงานจะแสดงสิ่งที่โหลดอยู่จริง ปุ่ม ⌄ เปิดรายละเอียด (กราฟิก API อัปสเกลเลอร์ โฟลเดอร์ `.exe` ชื่อของ OptiScaler ตัวเลือกการเปิดเกม) และคำสั่งที่ใช้ไม่บ่อย
- ปุ่มเป็นคริสตัลใสแบบนูน: สีอ่อนพร้อมขอบบาง แสงสะท้อนโค้งที่ครึ่งบน ประกายแสงตามขอบล่างด้านใน และเงานุ่ม ๆ ด้านล่าง ทั้งหมดเป็นชั้นโปร่งแสงสีเรียบ ไม่มีการไล่สี ปุ่มกลมของสวิตช์ก็นูนขึ้นแบบเดียวกัน และธีมที่เลือกเป็นคริสตัลนูนในร่องที่ลึกลง สีฟ้าอมเขียวคือติดตั้ง สีน้ำเงินคือเปลี่ยน สีเหลืองอำพันคืออัปเดต สีแดงคือลบ
- ธีมมืด สว่าง หรืออัตโนมัติ (ตามเดสก์ท็อป) บันทึกกิจกรรมอยู่ในลิ้นชักด้านล่างของหน้าต่าง

## HelixSR 2.0 และ GPU

- **ดาวน์โหลดและสร้าง HelixSR ในขั้นตอนเดียว**: "ดาวน์โหลดและสร้าง HelixSR" (ในหน้าต่าง HelixSR และในปลั๊กอิน Steam Deck) จะดาวน์โหลด HelixSR รุ่นล่าสุด (2.0 ขึ้นไป) จากหน้ารีลีสบน GitHub ตรวจสอบด้วย SHA-256 แล้วเก็บไว้ที่ `~/.local/share/scaler-assistant/helixsr` จากนั้นสร้างบนพีซีเครื่องนี้ด้วยโปรแกรมสร้างของ HelixSR เอง (`setup/helixsr_setup.py` รันตามเดิม) แบบเดียวกับแอปของ HelixSR จึงไม่ต้องใช้เทอร์มินัลและไม่มีขั้นตอนติดตั้งเกม สิ่งที่การสร้างต้องใช้ก็จัดเตรียมให้: Python ที่มี numpy (ใช้ Python 3.14 แบบพกพาเมื่อ Python ของระบบแตกแพ็กเกจ zstd ของ NVIDIA ไม่ได้ การสร้างเฟรมจึงไม่ต้องติดตั้ง `zstd` เพิ่ม) และ DirectX Shader Compiler ของ Microsoft ที่รันผ่าน Proton ของ Steam หรือ Wine ไฟล์ของ NVIDIA จะดาวน์โหลดหลังจากคุณยอมรับในแอปเท่านั้น และผลลัพธ์อยู่บนพีซีของคุณ ใน Flatpak การสร้างจะรันบนโฮสต์ การรันซ้ำจะสร้างเฉพาะส่วนที่ขาด และรีลีสใหม่จะแทนที่รุ่นที่ดาวน์โหลดไว้ก่อน
- **HelixSR 2.0 ขึ้นไป** เก็บ DLL ที่สร้างแล้วไว้ใน `HelixSR-fsrfg` และมีสองวิธี: **HelixSR Scaler** (OptiScaler ของ HelixSR เองวางข้าง `.exe`: เลือก DLSS ในเกม ใช้กับเกม DX11 และ Vulkan ได้ด้วย) และ **วิธี FSR** (FSR drop-in) ผู้ช่วย Scaler ติดตั้งทั้งสองวิธีผ่านตัวติดตั้งในโฟลเดอร์ HelixSR ของคุณ (`setup/helixsr_bridge.py` ตัวเดียวกับที่แอปของ HelixSR ใช้) ดังนั้น setup ของ HelixSR แอปของมัน และผู้ช่วย Scaler จึงรู้จัก อัปเดต และลบการติดตั้งของกันและกันได้ ชื่อไฟล์ยังคงเลือกโดยผู้ช่วย Scaler และจะเพิ่มตัวเลือกการเปิดเกมเมื่อจำเป็น เกมที่ตั้งค่าด้วยวิธีเดิมจะย้ายไปใช้ HelixSR Scaler เมื่ออัปเดต โฟลเดอร์ HelixSR 1.8 / 1.9 ยังมีสามวิธีเหมือนเดิม
- **การสร้างเฟรมของ HelixSR** (HelixSR 2.0): เกม DirectX 12 ที่มี DLSS Frame Generation (`sl.dlss_g.dll` ของ Streamline) เมื่อติดตั้ง HelixSR Scaler จะมีสวิตช์ "การสร้างเฟรมของ HelixSR" บนการ์ดเกม (และในปลั๊กอิน Steam Deck) สวิตช์นี้ใช้ตัวติดตั้งของ HelixSR เอง (`scaler-fg`) ซึ่งเปลี่ยนเฉพาะตัวเลือก `[FrameGen]` ใน OptiScaler.ini จากนั้นให้เปิด DLSS Frame Generation ในเกม ต้องมีการสร้างเฟรมที่ `./helixsr-setup.sh` สร้างไว้ (จะดาวน์โหลดไฟล์ DLSS Frame Generation ของ NVIDIA) ก่อนหน้านั้นสวิตช์จะเป็นสีเทาพร้อมเหตุผล การติดตั้งใหม่จะปิดไว้ การอัปเดตหรือเปลี่ยนชื่อไฟล์ OptiScaler จะคงสถานะเดิม เกม DX12 อื่นยังเลือกการสร้างเฟรม AMD FSR หรือ XeSS ได้ในเมนู HelixSR Scaler (Insert) ส่วนเกม DX11 / Vulkan และวิธี FSR มีเพียงการอัปสเกล
- **HelixSR 3.0**: DLL ที่สร้างแล้วอยู่ที่ `HelixSR/helixsr.dll` (ตัวอัปสเกล DLSS ของ HelixSR Scaler "HLX DLSS") และวิธี FSR จะติดตั้ง **HLX FSR 4** ซึ่งเป็นไปป์ไลน์ FSR 4 ของ HelixSR เอง setup ของ HelixSR สร้างมันจากไฟล์ไดรเวอร์ FSR 4 ของ AMD (ดาวน์โหลดประมาณ 420 MB จากแพ็กเกจไดรเวอร์ของ AMD; "ดาวน์โหลดและสร้าง HelixSR" จะถามก่อน และเตรียมคอมไพเลอร์เชดเดอร์ตัวที่สอง DXC 1.9.2609 ให้ด้วย) ผู้ช่วย Scaler ติดตั้ง อัปเดต สลับ และถอนทั้งสองวิธีผ่านตัวติดตั้งในรีลีสเหมือนกับ 2.0; เกมที่ตั้งค่าด้วย 2.0 จะย้ายจาก `HelixSR-fsrfg` ไป `HelixSR` เมื่ออัปเดต HelixSR 3.0 ไม่มีการสร้างเฟรม จึงไม่แสดงสวิตช์ด้านบนเมื่อใช้ 3.0; การสร้างเฟรมของ AMD FSR และ XeSS ยังอยู่ในเมนูของ HelixSR Scaler ตั้งแต่ HelixSR 3.2 HLX FSR 4 มาแบบสร้างเสร็จแล้วใน ZIP (สร้างจาก FSR 4.1.2 ใน FSR SDK 2.4.0 ของ AMD): setup ไม่ดาวน์โหลดแพ็กเกจไดรเวอร์ของ AMD อีกต่อไป และ FSR ของ AMD เองที่อยู่ข้างกันใน HelixSR Scaler เป็น FSR 4.1.2 HelixSR 3.2.1 เพิ่ม **Preset K** สำหรับ HLX DLSS เป็นตัวเลือกเสริม ซึ่งสร้างได้ด้วย setup ของ HelixSR เองเท่านั้น (`--preset-k`; "ดาวน์โหลดและสร้าง HelixSR" ไม่สร้างให้) เมื่อสร้างแล้วจะถูกติดตั้งลงเกมพร้อม HelixSR Scaler (`HelixSR/k`) และถูกลบออกพร้อมกัน รวมถึง log ของมันด้วย HelixSR 3.3 (HelixSR Scaler 2.3.0) ยังใช้โครงสร้างนี้: HelixSR Scaler แสดง HLX FSR 4 ในเกม Vulkan ด้วย และเคอร์เนล Vulkan แบบเนทีฟ (ตัวเลือกเสริม) ของ HLX DLSS จะสร้างโดย setup ของ HelixSR เองเท่านั้น (`--vulkan`; "ดาวน์โหลดและสร้าง HelixSR" ไม่สร้างให้ เกม Vulkan จึงยังใช้สะพาน DirectX 12 ของ HelixSR Scaler เหมือนเดิม) รุ่น 3.3 มาพร้อม HLX FSR 4 ที่สร้างเสร็จแล้วโดยไม่มีตัวสร้าง "ดาวน์โหลดและสร้าง HelixSR" จึงไม่ดาวน์โหลด DXC 1.9.2609 สำหรับมันอีก
- **HelixSR รุ่นก่อน**: 1.8.x ใช้ได้ทั้งสามวิธี (วิธี FSR, วิธี OptiScaler, วิธี DLSS) HelixSR 1.9.0 – 1.9.3 มีเฉพาะไฟล์ของวิธี FSR วิธี OptiScaler และวิธี DLSS จึงเป็นสีเทา ("ต้องใช้ HelixSR 1.8 หรือ 2.0") เกมที่ไม่มี FSR 3.1 ต้องใช้ HelixSR 2.0 (HelixSR Scaler) ไม่รองรับรุ่นก่อน 1.8.0
- **วิธี DLSS ใช้ได้เฉพาะ GeForce**: กับ GPU ของ AMD หรือ Intel เกมจะไม่ให้เลือก DLSS วิธี DLSS (HelixSR 1.x) จึงเป็นสีเทาพร้อมเหตุผล
- **แนะนำ FSR 4.1.2 Lite Lossy** สำหรับกราฟิกในตัว (Steam Deck, ROG Ally Z1 / Z2, Ryzen AI MAX) และ GPU ของ Intel: แสดง "★ แนะนำ" เฉพาะในตัวเลือก FSR 4.1

## ทำงานร่วมกับ setup ของ HelixSR

สำหรับ DLSS 3.7 ผู้ช่วย Scaler เขียนบันทึกการติดตั้ง (`helixsr-install.json`) ไฟล์สำรอง และชื่อไฟล์แบบเดียวกับ setup ของ HelixSR ดังนั้น `helixsr-setup.sh` / `helixsr-uninstall.sh` และผู้ช่วย Scaler จะรู้จักเกมของอีกฝ่าย setup ของ HelixSR จะมอง DLL FSR ในโฟลเดอร์ `ScalerAssistant` ของเกมเป็น DLL FSR 3.1 ของเกมเองและอาจแทนที่ด้วย HelixSR ผู้ช่วย Scaler จะแจ้งว่าเกมต้องซ่อมแซม และ "ซ่อมแซม" จะนำ HelixSR ออก หากต้องการใช้ DLSS 3.7 ในเกมนั้น ให้เลือกในผู้ช่วย Scaler

## ปลั๊กอิน Steam Deck (Decky Loader)

โปรแกรมเดียวกันสำหรับโหมดเกม เป็นปลั๊กอินของ [Decky Loader](https://decky.xyz) ในเมนูเข้าถึงด่วน

- **เกม**: เกมที่อัปสเกลได้ โดยเกมที่กำลังเล่นอยู่ขึ้นก่อน แต่ละเกมมีป้ายสถานะ และเมื่อเกมทำงานจะแสดงสิ่งที่โหลดอยู่จริง เลือกเกมเพื่อเลือก DLSS 3.7 (HelixSR ทุกวิธี) FSR 4.1 Exact / Lossy หรือ FSR 3 หรือเพื่ออัปเดต ซ่อมแซม ลบ เปลี่ยนชื่อไฟล์ของ OptiScaler หรืออ่านล็อก ก่อนทำจะถามเหมือนแอปเดสก์ท็อป: ไฟล์ดาวน์โหลด คำเตือนของ Lossy วิธี DLSS และระบบป้องกันการโกง
- **การตั้งค่า**: โฟลเดอร์ HelixSR (ตัวเลือกไฟล์) ไฟล์ดาวน์โหลดและบิลด์ FSR 4.1 (Steam Deck ได้บิลด์สำหรับกราฟิกในตัว) การแจ้งเตือนเมื่อเกมเริ่ม (บอกว่าอัปสเกลเลอร์โหลดแล้วหรือไม่) และภาษา (ค่าเริ่มต้นเหมือน Steam)
- ใช้ `state.json` ไฟล์ดาวน์โหลด และบันทึกตัวเลือกการเปิดเกมร่วมกับแอปเดสก์ท็อป เกมที่ตั้งค่าในฝั่งหนึ่งจะเห็นในอีกฝั่ง ตัวเลือกการเปิดเกมเขียนผ่าน Steam ทันที
- ไม่มีในปลั๊กอิน: ฟอร์มตั้งค่า HelixSR (ใช้แอปเดสก์ท็อป) และ `helixsr-setup.sh` ของ HelixSR ซึ่งต้องรันหนึ่งครั้งในโหมดเดสก์ท็อป
- ในปลั๊กอิน **ดาวน์โหลดและสร้าง HelixSR** ดาวน์โหลดและสร้าง HelixSR 2.0 ขึ้นไปได้ในโหมดเกมด้วย (ใช้เวลาหลายนาที)

การติดตั้ง: ติดตั้ง Decky Loader บน Steam Deck ดาวน์โหลด `Scaler_Assistant-Decky-<เวอร์ชัน>.zip` จากหน้า [Releases](https://github.com/mosesmoon/scaler-assistant/releases) แล้วไปที่การตั้งค่าของ Decky → Developer (เปิดโหมดนักพัฒนาใน General ก่อน) → "Install Plugin from ZIP File"

## การติดตั้งผู้ช่วย Scaler

**AppImage (แนะนำ)**: รวม Python, Qt และ 7-Zip ไว้แล้ว

1. ดาวน์โหลด `Scaler_Assistant-<เวอร์ชัน>-x86_64.AppImage` จากหน้า [Releases](https://github.com/mosesmoon/scaler-assistant/releases)
2. ทำให้รันได้: คลิกขวา → Properties → Permissions → "Allow executing file as program" (ชื่อเมนูต่างกันตามตัวจัดการไฟล์)
3. ดับเบิลคลิก

```bash
chmod +x Scaler_Assistant-*-x86_64.AppImage
./Scaler_Assistant-*-x86_64.AppImage
```

ถ้าเปิดไม่ขึ้น ระบบอาจไม่มี FUSE ให้รันด้วย `--appimage-extract-and-run`

**ตัวติดตั้งไฟล์เดียว (.bin)**: `Scaler_Assistant-<เวอร์ชัน>-x86_64.bin` ติดตั้งแอปชุดเดียวกันให้เฉพาะผู้ใช้ปัจจุบัน (ไม่ต้องใช้ root หรือ FUSE) ไว้ที่ `~/.local/opt/scaler-assistant` พร้อมคำสั่ง `scaler-assistant` และเมนู **Flatpak**: `Scaler_Assistant-<เวอร์ชัน>-x86_64.flatpak` เป็นแพ็กเกจไฟล์เดียวบน runtime Freedesktop 25.08 (ดาวน์โหลดจาก Flathub ตอนติดตั้ง) อ่านโฟลเดอร์ home และไดรฟ์อื่น (การ์ด SD ใต้ `/run/media`) ได้ และเห็นโปรเซสของ Steam และเกมผ่าน `flatpak-spawn --host`

```bash
sh Scaler_Assistant-*-x86_64.bin                # install / ติดตั้ง
sh Scaler_Assistant-*-x86_64.bin --uninstall    # remove / ลบ
flatpak install --user Scaler_Assistant-*-x86_64.flatpak
flatpak run io.github.mosesmoon.ScalerAssistant
```

**จากซอร์สโค้ด**: Python 3.11 ขึ้นไปและ PyQt6 (Arch: `sudo pacman -S python-pyqt6`) รวมถึง 7-Zip หรือ bsdtar สำหรับแตกไฟล์ OptiScaler (`sudo pacman -S 7zip`)

```bash
./scaler-assistant     # รันโดยตรง
./install.sh           # ติดตั้งไปที่ ~/.local/share/scaler-assistant และเพิ่มในเมนู
```

## ข้อจำกัดที่ทราบ

- **เฉพาะเกม Steam** วิธี FSR 4.1 / FSR 3 ตรวจสอบทีละไฟล์กับ OptiScaler 0.9.4 แล้ว แต่ละเกมทำงานต่างกัน ถ้ามีปัญหาให้ดูรายการความเข้ากันได้ของ OptiScaler หรือเปลี่ยนชื่อไฟล์ของ OptiScaler
- FSR 4.1 ในเกม Direct3D 11 และ Vulkan ทำงานผ่านเส้นทาง Direct3D 12 ของ OptiScaler และทดสอบน้อยกว่า
- HelixSR เปลี่ยนเร็ว ผู้ช่วย Scaler ต้องใช้ HelixSR 1.8.0 ขึ้นไปและอิงโครงสร้างของ 1.8.x / 1.9.x / 2.0.x / 3.0.x / 3.1.x / 3.2.x / 3.3.x
- ข้อความซ้อนไม่แสดงในโหมดเกมของ Steam Deck (gamescope) ปลั๊กอิน Decky จะแสดงเป็นการแจ้งเตือนของ Steam แทน
- ในภาษาไทย เวียดนาม มลายู และฮินดี เมนูคลิกขวาเป็นภาษาอังกฤษ (Qt ไม่มีคำแปลอย่างเป็นทางการ) Steam ไม่มีชื่อเกมภาษามลายูและฮินดี

## ที่เก็บข้อมูล

| ตำแหน่ง | เนื้อหา |
|---|---|
| `~/.config/scaler-assistant/state.json` | สถานะของผู้ช่วย Scaler: โฟลเดอร์ HelixSR รายชื่อเกม ภาษา บิลด์ FSR 4.1 ชื่อ OptiScaler ที่คุณเลือก และรายการที่เพิ่มในตัวเลือกการเปิดเกม (รับช่วงจากผู้ช่วย HelixSR ครั้งเดียว) |
| `~/.local/share/scaler-assistant/components/` | ไฟล์ OptiScaler และ FSR 4.1 ที่ดาวน์โหลด |
| `~/homebrew/plugins/scaler-assistant/` | ปลั๊กอิน Decky บน Steam Deck (ใช้สถานะและไฟล์ดาวน์โหลดเดียวกับด้านบน) |
| `<เกม>/…/ScalerAssistant/` | FSR 4.1 / FSR 3: DLL FidelityFX, `scaler-install.json`, `backup/` |
| `<เกม>/…/HelixSR/helixsr-install.json` ข้าง DLL FSR ของเกม | DLSS 3.7: บันทึกการติดตั้งของ HelixSR (ใช้ร่วมกับ setup ของ HelixSR) |
| `<เกม>/…/helixsr.ini`, `helixsr.log`, `OptiScaler.ini`, `OptiScaler.log` | การตั้งค่าและบันทึก |
