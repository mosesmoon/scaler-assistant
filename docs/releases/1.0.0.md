## English

> ⚠ Scaler Assistant contains no upscaler files. FSR 4.1 and FSR 3 need OptiScaler and the FSR 4.1 DLLs, which it downloads only when you agree. DLSS 3.7 needs HelixSR 1.8.0 or newer, downloaded and set up by you (`./helixsr-setup.sh`). Details: `docs/features/en.md`.

### First release (formerly HelixSR Assistant)

- One menu per Steam game: **DLSS 3.7 (HelixSR)** in its three ways, **FSR 4.1 Exact**, **FSR 4.1 Lossy** (AMD's own FSR 4.1 on RX 9000), **FSR 3**, or remove. Only the choices that work for the game are offered.
- Detects each game's graphics API (DX12, DX11, Vulkan) from its `.exe`, its upscalers and anti-cheat.
- Picks a file name for OptiScaler that works in the game (OptiScaler's compatibility list, Vulkan, a `dxgi.dll` that is already taken) and sets `OptiScaler.ini` for the chosen upscaler, line by line.
- Adds `WINEDLLOVERRIDES` to the game's Steam launch options when the name needs it: only that one entry is inserted and later removed; everything else you have there stays as it is.
- Downloads OptiScaler 0.9.4 and FSR 4.1 Exact / Lossy (build chosen from your GPU) on request, checked by SHA-256. Lossy shows its warning first.
- Switches, updates ("Update all"), repairs (also a missing launch option) and removes with every file put back. Works together with HelixSR's own setup.
- HelixSR settings as a form, live status of what is loaded in a running game, overlay on game start, 12 languages. Settings of HelixSR Assistant are taken over.
- **Liquid Glass look** after MAKO Assistant: a card per game with cover, status and details; clear crystal buttons without gradients; dark, light or automatic theme.
- **Steam Deck plugin for Decky Loader** (`Scaler_Assistant-Decky-1.0.0.zip`): the same choices, downloads, OptiScaler name and launch-option handling from the Quick Access menu in Game Mode, with a notification when a game starts. Shares settings and downloads with the desktop app.
- **Download and build HelixSR in one step** from the HelixSR window or the Steam Deck plugin: the newest release from GitHub, the build tools it needs, and HelixSR's own build — no terminal, games untouched.
- **HelixSR 2.0**: HelixSR Scaler and the FSR way, installed through HelixSR's own installer from your HelixSR folder. The DLSS way is greyed out without a GeForce; FSR 4.1 Lossy is marked as recommended on built-in graphics (Steam Deck, Z1 / Z2, Ryzen AI MAX) and Intel GPUs.
- **HelixSR frame generation**: a switch on the card (and in the Steam Deck plugin) for games with HelixSR Scaler and DLSS Frame Generation, through HelixSR's own installer.
- HelixSR 2.0's installer no longer stops with "Permission denied" when another game has a folder you can't read (for example a mod's `HelixSR` folder): such folders are skipped.
- Downloads in the Steam Deck plugin no longer fail with CERTIFICATE_VERIFY_FAILED: when the Python running the plugin can't find certificate authorities, the system's own are used (certificates are still checked).
- **More packages**: a single installer (`Scaler_Assistant-1.0.0-x86_64.bin`, no root or FUSE, `--uninstall` to remove) and a Flatpak bundle (`Scaler_Assistant-1.0.0-x86_64.flatpak`).

### Getting started

1. Make `Scaler_Assistant-1.0.0-x86_64.AppImage` executable and double-click it.
2. Click "Choose upscaler" on a game's card. For DLSS 3.7, set up HelixSR first (click the HelixSR pill).
3. Steam Deck Game Mode: install Decky Loader, then Decky settings → Developer → "Install Plugin from ZIP File" and pick `Scaler_Assistant-Decky-1.0.0.zip`.

- 從遊戲的 `.exe` 偵測繪圖 API（DX12、DX11、Vulkan），以及升頻技術與反作弊。
- 替 OptiScaler 選擇遊戲能用的檔名（OptiScaler 相容性清單、Vulkan、已被占用的 `dxgi.dll`），並依選擇的升頻技術逐行設定 `OptiScaler.ini`。
- 檔名需要時，在遊戲的 Steam 啟動選項加入 `WINEDLLOVERRIDES`：只插入、之後也只移除這一項；你原本的其他內容都保持不變。

- 可切換、更新（「全部更新」）、修復（包括消失的啟動選項）、移除，所有檔案都會放回。與 HelixSR 本身的 setup 互通。

- **Decky Loader 的 Steam Deck 外掛**（`Scaler_Assistant-Decky-1.0.0.zip`）：在遊戲模式的快速存取選單中做同樣的選擇、下載、OptiScaler 檔名與啟動選項處理，遊戲啟動時會通知。設定與下載檔和桌面版共用。
- **一鍵下載並建置 HelixSR**（HelixSR 視窗或 Steam Deck 外掛）：從 GitHub 下載最新版、備齊建置工具並執行 HelixSR 自己的建置，不需要終端機，也不會動到遊戲。

- 其他遊戲有你無法讀取的資料夾時（例如模組裡的 `HelixSR` 資料夾），HelixSR 2.0 的安裝程式不再因「Permission denied」中斷，這類資料夾會被略過。
- Steam Deck 外掛的下載不再出現 CERTIFICATE_VERIFY_FAILED：執行外掛的 Python 找不到憑證機構時，改用系統本身的憑證（仍會驗證憑證）。
- **更多安裝方式**：單一安裝檔（`Scaler_Assistant-1.0.0-x86_64.bin`，不需 root 或 FUSE，`--uninstall` 移除）與 Flatpak 套件（`Scaler_Assistant-1.0.0-x86_64.flatpak`）。

### 開始使用

1. 將 `Scaler_Assistant-1.0.0-x86_64.AppImage` 設為可執行並按兩下開啟。
2. 在遊戲卡片上按「選擇升頻」。使用 DLSS 3.7 前請先設定好 HelixSR（按 HelixSR 標籤）。
3. Steam Deck 遊戲模式：安裝 Decky Loader 後，到 Decky 設定 →「開發者」→「Install Plugin from ZIP File」，選擇 `Scaler_Assistant-Decky-1.0.0.zip`。

- HelixSR の設定フォーム、実行中のゲームで読み込まれたもののライブ表示、起動時のオーバーレイ、12 言語。HelixSR アシスタントの設定を引き継ぎます。

- **Decky Loader 用 Steam Deck プラグイン**（`Scaler_Assistant-Decky-1.0.0.zip`）：ゲームモードのクイックアクセスメニューから同じ選択、ダウンロード、OptiScaler の名前、起動オプションの処理ができ、ゲーム起動時に通知します。設定とダウンロードはデスクトップ版と共有します。
- **HelixSR のダウンロードとビルドを一度に**（HelixSR ウィンドウまたは Steam Deck プラグイン）：GitHub から最新版を取得し、必要なビルドツールをそろえて HelixSR 自身のビルドを実行します。ターミナル不要で、ゲームは変更しません。

- **HelixSR フレーム生成**：HelixSR Scaler と DLSS Frame Generation のあるゲームのカード（と Steam Deck プラグイン）にスイッチを追加。HelixSR 自身のインストーラーで切り替えます。

- **HelixSR 2.0**: HelixSR Scaler und der FSR-Weg, installiert über HelixSRs eigenes Installationsprogramm aus deinem HelixSR-Ordner. Ohne GeForce ist der DLSS-Weg ausgegraut; bei integrierter Grafik (Steam Deck, Z1 / Z2, Ryzen AI MAX) und Intel-GPUs ist FSR 4.1 Lossy als empfohlen markiert.

3. Spielmodus des Steam Deck: Decky Loader installieren, dann in Deckys Einstellungen → Entwickler → „Install Plugin from ZIP File“ die `Scaler_Assistant-Decky-1.0.0.zip` wählen.

3. Chế độ chơi game của Steam Deck: cài Decky Loader, rồi vào cài đặt Decky → Developer → "Install Plugin from ZIP File" và chọn `Scaler_Assistant-Decky-1.0.0.zip`.

## Bahasa Melayu

> ⚠ Pembantu Scaler tidak mengandungi fail upscaler. FSR 4.1 dan FSR 3 memerlukan OptiScaler dan DLL FSR 4.1, yang hanya dimuat turun apabila anda bersetuju. DLSS 3.7 memerlukan HelixSR 1.8.0 atau lebih baharu yang anda muat turun dan sediakan sendiri (`./helixsr-setup.sh`). Butiran: `docs/features/ms.md`.

### Keluaran pertama (dahulu Pembantu HelixSR)

- Satu menu bagi setiap permainan Steam: **DLSS 3.7 (HelixSR)** dalam tiga caranya, **FSR 4.1 Exact**, **FSR 4.1 Lossy** (FSR 4.1 asli AMD pada RX 9000), **FSR 3**, atau buang. Hanya pilihan yang berfungsi untuk permainan ditawarkan.
- Mengesan API grafik (DX12, DX11, Vulkan) daripada `.exe`, serta upscaler dan anti-tipu.
- Memilih nama fail OptiScaler yang berfungsi dalam permainan (senarai keserasian, Vulkan, `dxgi.dll` yang sudah digunakan) dan menetapkan `OptiScaler.ini` baris demi baris.
- Menambah `WINEDLLOVERRIDES` pada pilihan pelancaran Steam apabila nama memerlukannya: hanya satu entri itu dimasukkan dan kemudian dikeluarkan; yang lain kekal.
- Memuat turun OptiScaler 0.9.4 dan FSR 4.1 Exact / Lossy (binaan mengikut GPU) apabila diminta, disemak dengan SHA-256. Lossy menunjukkan amarannya dahulu.
- Menukar, mengemas kini ("Kemas kini semua"), membaiki (termasuk pilihan pelancaran yang hilang) dan membuang dengan semua fail dikembalikan. Berfungsi bersama persediaan HelixSR.
- Borang tetapan HelixSR, status langsung, paparan tindih semasa permainan bermula, 12 bahasa. Tetapan Pembantu HelixSR diambil alih.
- **Rupa Liquid Glass** mengikut MAKO Assistant: satu kad bagi setiap permainan dengan kulit, status dan butiran; butang kristal jernih tanpa kecerunan; tema gelap, cerah atau automatik.
- **Pemalam Steam Deck untuk Decky Loader** (`Scaler_Assistant-Decky-1.0.0.zip`): pilihan, muat turun, nama OptiScaler dan pengendalian pilihan pelancaran yang sama dari menu Akses Pantas dalam Mod Permainan, dengan pemberitahuan apabila permainan bermula. Berkongsi tetapan dan muat turun dengan aplikasi desktop.
- **Muat turun dan bina HelixSR dalam satu langkah** (tetingkap HelixSR atau plugin Steam Deck): keluaran terbaharu dari GitHub, alat binaan yang diperlukan dan binaan HelixSR sendiri — tanpa terminal, permainan tidak disentuh.
- **HelixSR 2.0**: HelixSR Scaler dan cara FSR, dipasang melalui pemasang HelixSR sendiri dari folder HelixSR anda. Tanpa GeForce, cara DLSS dikelabukan; grafik bersepadu (Steam Deck, Z1 / Z2, Ryzen AI MAX) dan GPU Intel ditanda FSR 4.1 Lossy sebagai disyorkan.
- **Penjanaan bingkai HelixSR**: suis pada kad (dan dalam plugin Steam Deck) untuk permainan dengan HelixSR Scaler dan DLSS Frame Generation, melalui pemasang HelixSR sendiri.
- Pemasang HelixSR 2.0 tidak lagi berhenti dengan "Permission denied" apabila permainan lain mempunyai folder yang tidak boleh anda baca (contohnya folder `HelixSR` sebuah mod): folder sebegitu dilangkau.
- Muat turun dalam plugin Steam Deck tidak lagi gagal dengan CERTIFICATE_VERIFY_FAILED: apabila Python yang menjalankan plugin tidak menemui pihak berkuasa sijil, sijil sistem digunakan (sijil masih disemak).
- **Lebih banyak pakej**: pemasang tunggal (`Scaler_Assistant-1.0.0-x86_64.bin`, tanpa root atau FUSE, `--uninstall` untuk membuang) dan pakej Flatpak (`Scaler_Assistant-1.0.0-x86_64.flatpak`).

### Bermula

1. Jadikan `Scaler_Assistant-1.0.0-x86_64.AppImage` boleh laku dan klik dua kali.
2. Klik "Pilih upscaler" pada baris permainan. Untuk DLSS 3.7, sediakan HelixSR dahulu (label HelixSR).
3. Mod Permainan Steam Deck: pasang Decky Loader, kemudian tetapan Decky → Developer → "Install Plugin from ZIP File" dan pilih `Scaler_Assistant-Decky-1.0.0.zip`.

## हिन्दी

> ⚠ Scaler सहायक में कोई अपस्केलर फ़ाइल नहीं है। FSR 4.1 और FSR 3 को OptiScaler और FSR 4.1 DLL चाहिए, जो सिर्फ़ आपकी सहमति पर डाउनलोड होती हैं। DLSS 3.7 के लिए आपका ख़ुद डाउनलोड और सेट अप किया HelixSR 1.8.0 या नया चाहिए (`./helixsr-setup.sh`)। विवरण: `docs/features/hi.md`।

### पहला संस्करण (पहले HelixSR सहायक)

- हर Steam गेम के लिए एक मेनू: तीनों तरीकों में **DLSS 3.7 (HelixSR)**, **FSR 4.1 Exact**, **FSR 4.1 Lossy** (RX 9000 पर AMD का अपना FSR 4.1), **FSR 3**, या हटाएँ। सिर्फ़ वही विकल्प दिखते हैं जो गेम में काम करते हैं।
- `.exe` से ग्राफ़िक्स API (DX12, DX11, Vulkan) पहचानता है, साथ में अपस्केलर और एंटी-चीट भी।
- OptiScaler के लिए गेम में चलने वाला फ़ाइल नाम चुनता है (संगतता सूची, Vulkan, पहले से इस्तेमाल `dxgi.dll`) और `OptiScaler.ini` को पंक्ति-दर-पंक्ति सेट करता है।
- जब नाम को ज़रूरत हो, Steam लॉन्च विकल्पों में `WINEDLLOVERRIDES` जोड़ता है: सिर्फ़ वही एक प्रविष्टि डाली और बाद में हटाई जाती है; बाकी सब वैसा ही रहता है।
- माँगने पर OptiScaler 0.9.4 और FSR 4.1 Exact / Lossy (GPU के हिसाब से बिल्ड) डाउनलोड करता है, SHA-256 से जाँचकर। Lossy पहले अपनी चेतावनी दिखाता है।
- बदलें, अपडेट ("सब अपडेट करें"), मरम्मत (गायब लॉन्च विकल्प भी) और हर फ़ाइल वापस रखकर हटाएँ। HelixSR के अपने setup के साथ काम करता है।
- HelixSR सेटिंग्स का फ़ॉर्म, लाइव स्थिति, गेम शुरू होने पर ओवरले, 12 भाषाएँ। HelixSR सहायक की सेटिंग्स अपने-आप ली जाती हैं।
- MAKO Assistant जैसा **Liquid Glass रूप**: हर गेम का कार्ड, कवर, स्थिति और विवरण के साथ; बिना ग्रेडिएंट वाले पारदर्शी क्रिस्टल बटन; डार्क, लाइट या ऑटोमैटिक थीम।
- **Decky Loader के लिए Steam Deck प्लगइन** (`Scaler_Assistant-Decky-1.0.0.zip`): गेमिंग मोड के क्विक एक्सेस मेनू से वही विकल्प, डाउनलोड, OptiScaler का नाम और लॉन्च विकल्पों का प्रबंधन, गेम शुरू होने पर सूचना के साथ। सेटिंग्स और डाउनलोड डेस्कटॉप ऐप के साथ साझा होते हैं।
- **एक ही चरण में HelixSR डाउनलोड करके बनाएँ** (HelixSR विंडो या Steam Deck प्लगइन): GitHub से नवीनतम रिलीज़, ज़रूरी बिल्ड टूल और HelixSR का अपना बिल्ड — बिना टर्मिनल, गेम अछूते रहते हैं।
- **HelixSR 2.0**: HelixSR Scaler और FSR तरीका, आपके HelixSR फ़ोल्डर से HelixSR के अपने इंस्टॉलर द्वारा इंस्टॉल। GeForce न होने पर DLSS तरीका धूसर; इंटीग्रेटेड ग्राफ़िक्स (Steam Deck, Z1 / Z2, Ryzen AI MAX) और Intel GPU पर FSR 4.1 Lossy अनुशंसित चिह्नित।
- **HelixSR फ़्रेम जनरेशन**: HelixSR Scaler और DLSS Frame Generation वाले गेम के कार्ड पर (और Steam Deck प्लगइन में) एक स्विच, जो HelixSR के अपने इंस्टॉलर से बदला जाता है।
- किसी दूसरे गेम में ऐसा फ़ोल्डर होने पर जिसे आप पढ़ नहीं सकते (जैसे किसी मॉड का `HelixSR` फ़ोल्डर), HelixSR 2.0 का इंस्टॉलर अब "Permission denied" पर नहीं रुकता: ऐसे फ़ोल्डर छोड़ दिए जाते हैं।
- Steam Deck प्लगइन में डाउनलोड अब CERTIFICATE_VERIFY_FAILED से विफल नहीं होते: जब प्लगइन चलाने वाला Python प्रमाणपत्र प्राधिकरण नहीं ढूँढ पाता, तो सिस्टम के अपने प्रमाणपत्र उपयोग होते हैं (प्रमाणपत्र अब भी जाँचे जाते हैं)।
- **और पैकेज**: एकल इंस्टॉलर (`Scaler_Assistant-1.0.0-x86_64.bin`, बिना root या FUSE, हटाने के लिए `--uninstall`) और Flatpak बंडल (`Scaler_Assistant-1.0.0-x86_64.flatpak`)।

### शुरुआत

1. `Scaler_Assistant-1.0.0-x86_64.AppImage` को चलने योग्य बनाएँ और डबल-क्लिक करें।
2. गेम की पंक्ति में "अपस्केलर चुनें" पर क्लिक करें। DLSS 3.7 के लिए पहले HelixSR सेट अप करें (HelixSR लेबल)।
3. Steam Deck का गेमिंग मोड: Decky Loader इंस्टॉल करें, फिर Decky की सेटिंग्स → Developer → "Install Plugin from ZIP File" में `Scaler_Assistant-Decky-1.0.0.zip` चुनें।
